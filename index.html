Questions

Can I resell this to unlimited clients?

Yes — the license covers your own use serving unlimited end-clients. It doesn't cover reselling the codebase itself to other developers.

Do I need to know Python?

You need to be comfortable running one and reading it. You're not writing new features to get started, but comfort with the language matters if you customize it.

What if I'm not using Gemini?

The LLM layer is a swappable interface — implement one method to add OpenAI, Anthropic, or anything else.

Does this include hosting?

No — you deploy it yourself (Render, Railway, or a VPS). The deployment guide walks through this step by step.

What's the refund policy?

7-day refund if the codebase doesn't run following the setup docs on a standard Python 3.11+ environment — not a general change-of-mind refund, since it's source code you can copy the moment you receive it.
